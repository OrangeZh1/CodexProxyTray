CodexProxyTray v0.2.5，统一守护与流量采集的暂停操作，并简化图表和版本信息。

## 守护与流量

- 暂停代理守护时同步停止流量采集；恢复守护后，按原先保存的“记录网络流量”选择恢复。统计原本关闭时，恢复守护不会自动开启统计。
- 保留真实停止确认；停止未完成时显示错误状态，不提前当作已暂停。暂停和恢复不会关闭 ChatGPT 或现有 CLI 会话。
- 流量图在采集初期按已有样本时间展开，采满两分钟后使用固定两分钟窗口。缺失样本保留间断，恢复采集不连接跨会话数据。
- 去掉鼠标点击图表时的黑色选中框，保留键盘导航的焦点提示；移除流量卡底部撑高布局的长诊断提示。
- 修复合法 CLI 父进程退出后的采集交接，以及已核验活跃子进程因缓存过期被误拒绝的问题；继续独立核验进程创建身份、所属用户和应用范围。
- 本次修复包含流量辅助服务 1.0.1。已安装 1.0.0 时，需要在设置中卸载辅助服务后重新安装一次，并完成 Windows 授权；之后仍按辅助服务的独立兼容版本判断是否需要更新。

## 版本信息

- CLI 管理区和助手更新区仅显示最新版本，移除重复的当前版本对比；应用详情及更新确认仍保留必要的已安装版本信息。
- 检查失败时保留同一安装目标上次查到的版本并明确标示，旧检查结果不会继续授权 CLI 更新。
- 助手更新状态和更新说明入口合并为稳定布局，减少检查前后的页面跳动。

配置、用量记录和日志继续保留。安装器和可选流量辅助服务的授权机制不变。
