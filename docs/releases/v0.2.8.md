CodexProxyTray v0.2.8 修复流量采集中断和模型价格同步失败，补全模型与服务商汇总，并让运行日志更容易排查问题。

## 流量统计与价格同步

- 个别进程无法确认归属时，**流量采集**会继续统计已核验的目标，并提示累计可能不完整。已开启流量统计的用户，升级助手后请在“设置”点击“更新辅助服务”，将服务更新到 1.0.2。
- **模型价格同步**支持 gzip 压缩传输，遇到临时网络故障会限次重试。重试时显示当前进度，失败后保留上次成功的参考价。
- 价格同步失败时，**运行日志**会显示失败阶段、耗时，以及已取得的 HTTP 状态和字节数。模型定价页可跳转到相关日志，运行日志页可直接打开本机日志目录。

## 用量与日常使用

- 模型和服务商汇总显示平均输出速度、首字等待和处理耗时。每项按整个所选范围内有可靠计时的记录计算，详情列出有效样本数。模型行显示实际服务商。
- 减少常驻状态文件写入和用量历史重复排序。用量趋势图支持方向键浏览，统计范围说明区分来源累计跳过与本范围跳过的记录。
- 编辑代理端口后会提示“尚未应用”。CLI 管理操作支持取消和超时收尾，关闭流量日志时会保存最后一批采样。

## 安装与更新

已有用户可在助手内下载并重启更新，也可运行 Windows x64 Setup 沿用原安装目录。内置更新自动核对 SHA-256，用户无需手动校验。Windows 安装包和主程序未作 Authenticode 签名。
