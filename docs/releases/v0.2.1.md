CodexProxyTray v0.2.1，完善助手更新、CLI 安装与后台管理，改善用量和流量展示。

## 新增

- 助手支持后台下载官方安装包、校验后等待用户点击重启安装，保留配置和更新前日志归档；启动失败时尝试正常回退。
- 未安装 Codex CLI 时可通过当前用户 npm 安装。CLI 更新在后台进行，界面明确比较当前版本与最新版本。
- 可选的本机流量日志保留连接地址、端口、所属进程和流量采样；不记录通信内容，不上传。

## 优化与修复

- 用量扫描展示实际文件数和读取量，部分数据可查看具体原因；缩小日期范围复用元数据，已访问范围先显示缓存。
- 改善表格字号、对比、费用精度和边距，速度列加粗；价格同步等待间隔不再作为失败，按钮显示剩余等待时间。
- 抽屉和弹窗保留窗口控制区；置顶按钮保持图钉图标。
- 进程发现到采集器绑定期间保留已验证句柄，并有界暂存计量元数据，按真实存活区间回补；实际未覆盖记录报告数量和时段。
- 仪表盘移除最近事件，调整卡片比例。流量图使用稳定的两分钟范围，统一刻度、单位与时间轴；区分采集中和累计覆盖不完整。
- 内部代理启动入口不再以同名 codex 命令加入 PATH，保留一套官方 npm 安装；从助手打开时仍注入代理。

## 使用说明

本机用量与费用为日志和参考价估算，不能代替正式账单。流量按已验证进程合计；连接历史不提供域名、代理规则、节点或单连接计量。

本版本仍未作 Authenticode 数字签名。安装包通过固定官方 Release 与 SHA-256 校验；流量辅助服务仍单独管理，不自动完成 Windows 授权，不关闭 ChatGPT 或正在运行的 CLI 任务。
