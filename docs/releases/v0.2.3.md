CodexProxyTray v0.2.3，提供标准 Windows 安装入口，并改善更新下载与结果记录。

## 安装与卸载

- 新增 Windows x64 Setup EXE，按当前用户安装，注册“已安装的应用”、卸载入口和一个正常启动的开始菜单入口。
- 当前版本和上一版本代码单独管理，卸载器位于版本替换目录之外。配置、日志和用量索引继续单独保存，卸载助手保留这些数据。
- 合并已核验归属的旧“更新通知”快捷方式；内部 CLI 不创建开始菜单入口。历史归档、回退代码和未知文件不会为了清理搜索结果而删除。
- 可选流量辅助服务继续独立管理，涉及管理员权限的操作由本人授权。

## 更新修复

- 对尚未取得响应的瞬态连接或超时错误进行有限次数的安全 GET 重试，保留 TLS、官方域名、包白名单和 SHA-256 校验。
- 持久记录本次下载失败阶段和目标版本；重新打开时不再把旧的成功安装记录当成本次结果。
- 确认更新成功后自动打开助手主窗口，并增加真实窗口可见、未最小化的验收。ChatGPT 和正在运行的 CLI 不随助手更新重启。

首次建立用量索引或扩大历史范围仍可能后台读取。旧 v0.2.1 及更早流量服务迁移到独立兼容机制时，需要卸载后重装一次。

本版本未作 Authenticode 数字签名，发行附件提供 SHA-256 校验。仅当前用户的安装注册不等于管理员服务授权。
