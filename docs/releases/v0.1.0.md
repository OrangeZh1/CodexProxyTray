CodexProxyTray 首个 GitHub 正式版本，面向 Windows x64，采用完整解压后运行的便携发行包。

## 解决的主要问题

- 不想为了 ChatGPT / Codex 开启 TUN 或系统全局代理、影响其他软件：通过现有代理客户端的本地 HTTP / mixed 端口，单独为目标应用提供代理环境。
- 为与代理未传入进程、启动环境不正确有关的 `Reconnecting 1/5～5/5`、浏览器正常而桌面应用仍连不上等场景，提供统一的代理启动环境和连接诊断。
- 保留 Windows 桌面应用的包身份，检测应用包版本变化并重新建立守护，避免固定旧版本 EXE 路径。
- 接入本机 Windows Codex CLI，向目标子进程传入代理，保留参数和退出码；不修改系统代理或全局代理环境变量。
- 将持续守护、应用启动和状态检测集中到托盘程序，保留正在进行的任务。

## 界面与诊断

- 仪表盘展示本地代理耗时趋势、ChatGPT 运行状态、TCP 连接、网页探测和守护时长。
- 日志支持完整详情、级别与关键词检索、日期范围、今天 / 昨天 / 近 7 天快捷筛选和一键重置。
- 设置支持浅色 / 深色 / 跟随系统、登录自动启动、启动后打开的应用、CLI 工作目录及联网偏好。
- 加入侧栏、页面、标签、弹窗与操作反馈动效，并修复开发预览阶段的主窗口空白、设置切换空白、侧栏偏移、弹窗退出闪空及窄窗口日期控件对齐问题。
- 可选进程流量统计配有独立辅助服务，修复管道回复、ETW 查询和停止确认问题；只计数字节，不读取内容或保存连接地址。

## 下载与使用

下载 `CodexProxyTray-v0.1.0-windows-x64.zip`，完整解压到固定目录，先启动本地 HTTP / mixed 代理，再运行 `CodexProxyTray.exe`。不要单独移动其中一个 EXE。包内包含离线中文使用说明、许可、文件校验值和编译来源回执。

需要 Microsoft Edge WebView2 Runtime，以及你要使用的 ChatGPT 桌面端或 Windows Codex CLI。已运行的 ChatGPT 需要在保存工作后手动完整退出并重开；CLI 首次接入后请新开终端。

## 使用范围

- 本项目主程序当前未作 Authenticode 数字签名；发布页提供 SHA-256 校验文件。
- 流量辅助服务的安装、重装和卸载需要本人完成 Windows 授权。已有服务与当前应用不匹配时，请先卸载再重装；日常开关统计无需反复授权。
- 日志最多保留最近 200 条，日期筛选只查询已保留记录。
- 本地端口或网页探测成功不保证登录、对话或所有请求可用。历史案例中的重连、“结束 WSL”和提示词异常属于使用反馈，不是对所有同类故障的修复承诺。
- WSL、远程主机和容器内的代理需要单独配置；助手不关闭 WSL，也不修改账号、模型提供方或内置提示词。
- 助手不会切换代理客户端的 TUN、系统代理或分流开关；如果客户端仍开启这些模式，其他软件仍按客户端已有规则联网。

本项目为社区工具，与 OpenAI 无隶属关系。
