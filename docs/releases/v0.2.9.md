CodexProxyTray v0.2.9 修复 Windows 拒绝查询单个进程映像时，仪表盘网络流量显示“暂不可用”、上传和下载读数同时消失的问题。

## 流量统计

- 辅助服务 1.0.3 可以通过 Windows 原生路径核验 ChatGPT 或已配置的 Codex CLI，也可以通过已核验的父进程和创建时间识别子进程。能确认归属的目标继续计数。
- 如果仍有目标无法确认归属，仪表盘会提示累计可能不完整，同时保留其他已核验目标的读数。

## 更新方法

在助手内检查更新并下载，或运行本页的 Windows x64 安装包。**已使用流量统计的用户，更新助手后，请到“设置 → 流量辅助服务”点击“更新辅助服务”，将服务升级到 1.0.3。** 完成一次 Windows 授权后，原有统计开关会保留。
