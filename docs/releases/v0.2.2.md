CodexProxyTray v0.2.2，改进流量服务兼容、后台用量读取与状态展示。

## 优化与修复

- 流量辅助服务使用独立版本和协议，不再要求助手与服务的整个 EXE 哈希相同。保留受保护服务文件的完整性校验、用户与进程身份检查；采集端独立核验 ChatGPT / Codex CLI 目标范围。
- 用量统计在后台持续读取，切换页面不中断。持久保存用量元数据和文件读取位置，重启后复用未变化文件，追加内容增量读取，不保存对话正文。
- 移除大扫描进度卡，将“部分数据”细分为后台同步、等待来源日志写入、来源记录跳过和范围限制；可查看具体数量与原因。来源历史的问题不直接等于所选日期缺少同样数量的数据。
- 保存手动开启或暂停守护的选择，退出时释放运行状态，不覆盖偏好。没有保存记录时默认暂停。
- 更新检查失败时保留上次成功查到的版本并标明状态；手动重试重新请求。检查完成后清理独立加载状态，移除成功安装及 CLI 检查的重复完成提示。
- 调整流量图两侧留白与时间轴，守护按钮对齐内容卡片右边缘；压紧实时连接列表，简化 CLI 版本比较，移除日志数量和桌面下载提示。

## 升级说明

- 从 v0.2.1 及更早版本升级时，流量辅助服务需要在设置中卸载后重新安装一次，以迁移到独立兼容机制；后续兼容的助手更新无需重装服务。Windows 授权由本人完成。
- 首次使用 v0.2.2 且没有保存过守护偏好时，守护默认暂停；需要代理守护时手动开启，之后会记住该选择。
- 初次建立索引、扩大历史范围、文件被替换或索引不兼容时仍可能扫描；后台读取与本机缓存不代表所有来源都完整。

本机用量与费用仍为日志和参考价估算，不能代替正式账单。流量仅计算已核验目标进程的字节，不读取通信内容。

本版本未作 Authenticode 数字签名。发行包与更新清单提供 SHA-256 校验。更新助手不自动操作流量服务，也不关闭 ChatGPT 或正在运行的 CLI 任务。
