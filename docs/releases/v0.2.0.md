CodexProxyTray v0.2.0，新增本机用量统计、模型参考价和应用管理，统一界面交互与诊断展示。

## 新增

- 用量统计读取本机 Codex 会话中的用量元数据，展示 Token、缓存、模型和服务商汇总，支持时间筛选、分页及自定义表格列；速度、首字时间在日志具备可靠边界时显示，估算值带有标记。
- 模型定价使用独立管理窗口，支持 models.dev 参考价自动同步、手动同步及本机自定义单价；费用可切换为美元或人民币，参考汇率不可用时保留未知状态。
- 增加主窗口置顶、工作目录选择器、受支持 npm 安装的 CLI 管理，以及 ChatGPT 桌面进程操作前的目标核对。
- 增加连接、内存和用量详情；网页出口地区显示本地打包的国旗。

## 优化与修复

- 统一主题色、侧栏、下拉菜单、选中状态、焦点圈和滚动条，修复弹窗边缘裁切；补充展开、关闭和新增请求反馈动效。
- 流量图时间改为悬停显示，采样断档不再用直线连接；图表刻度、边距与内容对齐。
- 修复用量元数据达到保留上限后停止增量读取的问题，持续接收最新记录，并提示历史截断；尚未写完的会话尾行明确显示为部分数据。
- 修复启动后安装或移除 CLI 时管理状态没有重新识别的问题；后台本地识别不触发联网更新，也不覆盖正在执行的管理操作。
- 便携包纳入第三方版权与许可正文，并校验文件白名单、哈希与编译来源回执。

## 使用说明

下载 `CodexProxyTray-v0.2.0-windows-x64.zip` 并完整解压，保留全部运行文件、许可和校验文件。需要 Microsoft Edge WebView2 Runtime，以及要使用的 ChatGPT 桌面端或 Windows Codex CLI。

用量与费用为本机日志和参考价的估算，不代表官方账单、订阅余额或实际付款。缺少单价、汇率或处理时间时不补造数据。本机用量保留最近 100,000 条元数据；更早记录未计入时会提示部分数据。

本版本主程序未作 Authenticode 数字签名，发布页提供 SHA-256 校验。流量辅助服务的安装与卸载仍需本人完成 Windows 授权；不会自动关闭正在运行的 ChatGPT、CLI 任务或 WSL。
