CodexProxyTray v0.2.10 新增可选的终端接入。开启后，在普通 CMD 或 PowerShell 的项目目录输入 `codex`，即可通过助手配置的本地代理启动 Codex CLI。

## 开启终端接入

1. 保持代理客户端运行，在助手的“代理”页确认本地 HTTP 或 mixed 端口可用，并开启守护。使用这个入口时可以关闭 TUN。
2. 打开“设置 → Codex CLI → 终端接入”。新开关默认关闭。
3. 完全退出并重新打开 CMD、Windows Terminal 或承载终端的编辑器，在项目目录运行 `codex`。在 CMD 中可以用 `where codex` 查看命令入口，用 `codex --proxy-info` 核对守护状态和代理地址。

终端接入使用已安装的 CLI，并保留当前目录和命令行参数。对支持独立会话的 CLI，助手会在新会话中使用当前代理。暂停守护后，后续启动沿用终端自身的代理环境。关闭终端接入并重开终端，即可恢复官方命令入口。

已有用户可在助手内检查更新、下载并重启，也可运行本页的 Windows x64 安装包，沿用原安装目录。
