# 图标来源

界面图标统一来自 Iconify 的 Fluent 集合。构建脚本只提取用到的图标，随应用本地打包，运行时不访问图标 CDN。

- 组件：Iconify React，https://github.com/iconify/iconify
- 图标集：Microsoft Fluent System Icons，https://github.com/microsoft/fluentui-system-icons
- 分发包：@iconify-json/fluent 1.2.61
- 图标作者：Microsoft Corporation
- 许可：MIT；许可原文保留在 fluent-icons-license.txt。

应用 Logo 沿用本项目已选定的独立 C / 箭头设计，源文件为 ui/icon.svg。
